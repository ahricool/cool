# 鸣神大社欢迎场景

`/` 为《原神》鸣神大社的程序化微缩改编，不使用或提取游戏模型、纹理。它保留神樱的狐形轮廓、巨型粉紫花冠、金边深色屋檐与千木、朱红鸟居和山顶高差；为原有正方形首页底座压缩了布局，并非声称精确复原游戏地图或尺寸。右上角进入按钮、时间控制、主题和所有其他路由不变。

主殿与社务殿位于轴线两侧，给神樱留出空间；三座鸟居随石阶升高。石灯笼、狐像、绘马架、御神签、净手盆、苔石与灌木服从空间布局，不增加无关大型水池。树冠使用不同形状、尺寸与高度的花团和 8,000 个单次实例绘制的五瓣花，花瓣飘落另外使用一个小型实例批次。

## 代码组织

- `model.ts`：共享建模工具、原生标准材质与静态合批。
- `architecture.ts`：实体曲线屋顶、瓦脊、金边、千木、梁柱、门廊、鸟居、栏杆。
- `sakura.ts`：渐细曲线木干、根部、狐形轮廓、青色裂隙、花冠与实例化花朵。
- `garden.ts`：方形石砌底座、连续高差、参道、建筑和庭院的统一布局。
- `environment.ts` / `daylight.ts`：天空渐变、雾中远山、周期昼夜光照和灯笼。
- `world.ts`：相机与 OrbitControls、花瓣动画、尺寸适配、暂停、慢帧降级和资源释放。

没有新增依赖。建模几何一次生成、静态合批，花朵与落瓣实例化；限制像素比与阴影分辨率，太阳变化时才更新静态阴影。相机的最近轨道在全部主体几何的外包球之外，禁止穿入模型、翻到地底或任意平移。减少动态效果设置使用按需绘制；连续六次慢帧触发降级时立即补画，避免调整像素比清空最后一帧。

## 启动与验证

要求 Node.js 24。首次安装后：

```sh
npm ci
npm run db:generate
npm run dev:frontend
```

打开 `http://127.0.0.1:3001/`。拖动旋转、滚轮或双指缩放，右上角箭头进入 `/home`。场景本身无需外部资源；博客内容需要后端。

```sh
npm run typecheck
npm run build
npm run lint
npm run test:unit
npm run test:content
npm run test:themes -- welcome.spec.ts
```

浏览器测试运行真实生产前端与 WebGL，但使用仓库现有的合成 API 内容夹具，不代表真实博客数据。视觉检查应覆盖默认全景、神殿近景、神樱、庭院、移动端、昼夜变化。帧率取决于设备与驱动，不能以三角形预算或通过构建来宣称 50–60 FPS；软件 WebGL 的测量结果也不代表普通硬件 GPU。
