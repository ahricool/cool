# 博丽神社欢迎场景

`/` 是一个漂浮在云海上的博丽神社微缩模型：明亮、二次元、樱花主调，以三渲二描边着色呈现。场景全部程序化生成，不加载模型、贴图或字体；角色像素图在运行时绘制到画布。右上角时间滑条、进入按钮与所有其他路由保持不变。

## 构图

- **底座**：完整正方形、轻微圆角。顶层草坪、木制夹层带竖向板缝、三层错缝石砌侧面，石块略凸出灰缝以形成清晰轮廓。
- **前低后高**：前院 (+z) 为最低层，铺碎石与两列错缝石板参道；石阶与狛犬通往石砌挡墙上的本殿高台；本殿高台后方是杉树、阔叶树，左后方是带岩石的小土丘和最大的一棵樱花，最高点在后方。
- **本殿**：流造屋顶，前坡长、向下延伸覆盖木阶与向拝柱；黑棕瓦面带瓦垄、白色破风板、金色端饰和出檐椽头。高架木地板、外廊与朱红栏杆、红柱白壁、格子门与蔀户、侧面障子窗、山墙白壁、额。正面有赛钱箱、神社铃、红白铃绳、注连绳与纸垂、两盏红灯笼。
- **周边**：右后社务所（障子门、暖帘、外廊、木桶、木箱、酒樽、风铃、灯笼），左侧仓库（海鼠壁、木门、扫帚、水桶），左前手水舍（石盆、水面、竹筒、柄杓），右前绘马架、御神签架、告示牌，参道两侧石灯笼，前院入口鸟居与注连绳。
- **院落生活感**：木栅栏、高台朱红玉垣、通往社务所与仓库的踏石小径、灌木与杜鹃、岩石与苔、小石堆、野花、深浅草坪斑块、满地落樱与落叶。

## 着色

- `toon.ts` 使用 MeshToonMaterial 与柔和过渡的两色光照纹理；颜色写入顶点色。亮面接近原色，阴影来自偏蓝紫的天光，不使用色调映射以免颜色发灰。
- 描边使用反向外壳：每个部件计算平均法线，在世界空间外扩，宽度随距离轻微补偿；颜色为填充色压暗后偏暖紫，而非纯黑，夜间随光照变暗。细小部件（瓦垄、格栅条、花朵）不描边，避免画面发脏。
- 轻微的天空色边缘光帮助剪影与背景分离。
- 晨昏使用独立的暖粉色天空与橙色地平线，而不是白天与夜晚的灰色中间值；夜晚为蓝调，石灯笼与纸灯笼点亮并闪烁，出现星空。

## 动效

所有动效都很克制，保持「精致静态模型」的观感：

- 樱花与树冠、草叶随风摇曳，纸垂、绘马、铃绳、灯笼与风铃绕挂点摆动——均在顶点着色器中完成，不逐帧更新几何。
- 花瓣从樱树飘落；云海缓慢环绕；灵光微粒白天几乎不可见，夜晚像萤火；灯笼火光闪烁。

## 灵梦

- 运行时用代码逐像素绘制 40×44 的 Q 版图集：红白巫女服、深棕头发与鬓发发筒、大红蝴蝶结（白色荷叶边）、白色分离袖、黄色领结、红鞋与扫帚。帧包括 4 帧扫地、待机/呼吸/眨眼、起跳预备、腾空、落地缓冲。外轮廓为降低饱和度的暖深色，颜色整体略柔和以融入场景。
- 角色是受光的面片：朝向相机但保持底边贴地，法线上倾以与地面受光一致，可接受场景阴影。脚底始终贴合 `layout.ts` 中的地面高度（草地、碎石、石板）。
- 阴影由两部分组成：柔和的接触阴影，跳跃时留在地面并变大变淡；以及沿太阳方向投影到地面的半透明剪影阴影。
- 行为：以约 7fps 扫地若干次 → 停顿（呼吸、眨眼），每隔一次停顿转身，使左右交替扫地 → 每第三次停顿后起跳，在 0.8–2.8 范围内跳到前院另一块空地，避开鸟居、灯笼、手水舍、绘马架等。扫地的前推帧会推动附近的落樱和落叶，它们滑动、旋转、轻微扬起后停下。
- 极轻微的呼吸起伏与重心左右移动；裙摆与蝴蝶结在帧间交替，不做夸张动画。

## 性能

默认视角约 17 次绘制、22 万三角形。静态阴影贴图仅在时间变化时更新，角色阴影不依赖阴影贴图。移动端减少草叶、花瓣、灵光与云数量，降低阴影贴图分辨率与像素比；连续慢帧时自动降级。减少动态效果设置冻结所有动画。
