# 梦桜前端设计原则

- 公共页与 Admin 共用 Sakura 组件、语义 token、字体和明暗主题。基色为粉 `#ff6699`（暗色 `#d34e7e`）及灰、白、黑；暗色页面 `#17181a`。成功、警告、危险也使用这套颜色，不引入绿色、橙色或蓝色状态装饰。操作语义由图标、文案和确认表达，不能只依赖颜色。
- 按钮、标签、徽标、Toast 无硬边框。用克制的组件 `box-shadow` 区分层次，hover 可略增强；图标用 `drop-shadow`，图片上的短文字用轻微 `text-shadow` 保证可读性。阴影不是大块彩色背景，也不只用于 focus ring；避免给所有正文施加厚重阴影。输入框、正文表格与清晰键盘焦点保留必要轮廓；用户 Markdown 的分隔线和语法高亮属于内容，不作装饰清理。
- 主操作采用深粉实心、白字。危险操作保留明确文案与确认；禁用状态可辨。控件视觉克制，触控目标至少 44px；移动搜索文字至少 16px。
- Toast 统一经 `utils/toast.ts` 调用：左上导航下方，Admin 避开固定侧栏；主题表面、圆角、柔和投影，语义图标与文字明确。沿用 alert、堆叠、悬停暂停与现有超时；重要错误仍保留页面内信息。
- 使用原始 `sakura.svg`，五瓣固定 `#ff6699`、透明度 0.8，不以遮罩重着色。品牌及 Footer 樱花 12 秒平滑旋转，尊重 reduced motion；SVG 字标路径保持原样。
- 背景、默认头像与封面共享生成器，每次只使用一种图形。心形/星形 19.5px、圆点 15px、横向间距 72px。扩大头像容器不扩大 tile；账户自定义头像优先，空时直接使用图案；网站配置不再存姓名或头像。全站作者姓名/头像唯一来源为账户，简介仍为网站双语内容。背景八色属于既有图案，用户图片、正文及数据图表原色保留。
- 头像上传预览使用 1:1 容器并保持原图比例；封面预览保留横图用途。不修改或重裁剪上传资源。
- 字体按需加载；字体大小 80–150%，默认 100%。缩放文字，不缩放导航图标；不同字体与最大字号都需检查窄屏。
- Admin 侧栏所有分辨率固定显示，窄屏压缩留白并让内容换行。顶部与左侧共用单次模糊背景；主题按钮统一右下悬浮。真实头像菜单承载网站配置、账户与退出，支持鼠标、触屏、键盘与 reduced motion。
- 归档条目只用日期、年月层级和留白组织，不加条目横线或厚重阴影分隔。
- 产品文案只保留操作、内容和必要反馈。不要恢复面包屑、技术宣传、冗余 label、抽屉搜索/关闭 ×、首页 hero 头像或旧技术署名。

修改共享视觉后，查看实际桌面/手机、浅色/暗色截图，检查滚动、焦点、弹层、长文本及未保存内容，再运行必要业务验证。

- 分享按钮直接绘制单层背景与投影，不增加伪元素按钮；保留 44px 点击区域。公开搜索输入与按钮作为整组居中。
- 表格操作列给按钮、投影及焦点留出上下空间，窄列可换行，不恢复装饰横线。
- 正文插入图片先打开复用的媒体库选择器；新图在选择器内上传后再选择。取消不改正文，保留当前语言、选区及撤销/重做。封面、头像仍保留直接上传的语义。
